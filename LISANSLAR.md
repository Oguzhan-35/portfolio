# Lisanslar ve kaynaklar

Bu depoda üçüncü taraflara ait tek varlık yazı tipidir. Geri kalan her şey
(logo, ekran görüntüleri, metinler, kod) Oğuzhan Kul'a aittir.

---

## Yazı tipi

### Manrope

| | |
| --- | --- |
| Dosyalar | `assets/fonts/manrope-var-latin.woff2`, `assets/fonts/manrope-var-latin-ext.woff2` |
| Tasarımcı | Mikhail Sharanda |
| Lisans | **SIL Open Font License 1.1** |
| Lisans metni | https://scripts.sil.org/OFL |
| Kaynak | https://github.com/sharanda/manrope |

SIL OFL 1.1, yazı tipinin gömülmesine, değiştirilmesine ve yeniden
dağıtılmasına izin verir. Tek koşul: yazı tipi tek başına satılamaz ve
türetilmiş sürümler "Manrope" adını taşıyamaz. Bu projede dosyalar
değiştirilmeden, yalnızca `latin` ve `latin-ext` alt kümeleri halinde
sunulmaktadır.

Yazı tipi kendi sunucumuzdan servis edilir; Google Fonts'a **hiçbir istek
gitmez**. Bu bir tasarım tercihi değil, gizlilik tercihidir: Google Fonts
üzerinden çekilen bir yazı tipi ziyaretçinin IP adresini üçüncü bir tarafa
iletir (bkz. Münih Eyalet Mahkemesi, 20 Ocak 2022, 3 O 17493/20).

## Görseller

| Varlık | Kaynak |
| --- | --- |
| `assets/img/logo.png`, `logo-dark.png` | Oğuzhan Kul / Koe Design'a ait logo. Zemin renkleri sayfa temasına uyacak şekilde yeniden işlendi. |
| `assets/img/og-cover.jpg` | `assets/img/og-cover.html` dosyasından üretildi (bu depodaki kaynaktan). |
| `assets/img/websites/*.jpg` | Oğuzhan Kul tarafından geliştirilen sitelerin ekran görüntüleri. |

Ekran görüntülerindeki sitelerde kullanılan fotoğrafların lisans kayıtları,
ilgili projelerin kendi `LISANSLAR.md` dosyalarında tutulur.
